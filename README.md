# Home-Cybersecurity-Lab-Attack-Simulation-Detection-and-Incident-Reporting
This project documents the development of a home cybersecurity lab used to practice both red team and blue team skills in a controlled virtual environment. The lab is designed to simulate basic attacker activity, observe defensive behavior, collect security logs, and document findings in a professional format.

The purpose of this project is to build hands-on cybersecurity experience by connecting offensive testing with defensive monitoring. Raider is used as the red team testing machine, while Sentinel is used as the blue team Windows endpoint. As the project grows, additional monitoring tools such as Sysmon, Wazuh, and Splunk will be added to improve visibility and create a more realistic security monitoring environment.

This lab is built for educational purposes only. All testing is performed inside a private virtual lab environment.
